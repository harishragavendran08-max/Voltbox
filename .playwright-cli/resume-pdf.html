Complete Application Feature Inventory All Modules & User Flows Implemented

1. Storefront, Smart Search & Filters Core UI

Instant client/server search across titles, SKUs, and hardware categories; quick stock filters (All / Available Now / Backorder); Best Deal vs 6-month average sorting; right-click & long-press quick context menus; progressive local-tile-to-photo image loading; and iOS-inspired Light/Dark theme switcher with haptic feedback.

2. Spec Drawer & D3/Recharts Telemetry Analytics

Slide-over hardware specification sheet with tabbed scroll-spy navigation, verified buyer reviews & helpfulness voting, animated price odometer rolls, Recharts historical sparklines, and D3.js 6-month volatility analysis featuring rolling bands, Z-score spikes, zoom/pan, and GSAP transitions.

3. Optical Product QR Scanner & Generator Vision / QR

Live webcam viewfinder and image upload decoder combining native BarcodeDetector with multi-pass contrast-stretched & quiet-zone jsQR decoding; 4 interactive corner drag handles to resize the scan reticle; 5-second visual countdown ring; WebAudio ping toggle; 10-item scan history; and manual SKU/URL/JSON lookup.

4. PC Rig Builder & Side-by-Side Compare Builder

Interactive 4-slot PC build planner (CPU, GPU, Motherboard, Storage/Memory) with compatibility progress meter, real-time PSU wattage estimator, 1-click Starter Rig auto-fill, automatic 5% bundle discount calculation, promo code engine, and multi-product side-by-side spec comparison modal.

5. Multi-Mode Checkout, UPI QR & Receipts Commerce

Server-verified cart & checkout pipeline supporting interactive UPI QR Overlay (GPay/PhonePe/Paytm VPA, copy button, 5-minute countdown timer), Card, NetBanking, and EMI modes; printable thermal-paper receipts embedded with Code-39 barcodes & QR hashes; and 4-stage live order tracking.

6. Hardware Concierge & Community Hub Realtime

Multi-channel Workspace Messenger (general, rig-builds, price-drops) with quick prompts, emoji reactions, and typing indicators; contributor application queue; listing flag/report workflow; and real-time WebSocket broadcasts for approvals, catalog changes, and active presence.

7. Admin Console & Batch Transactions Admin RBAC

Dedicated admin dashboard (/admin) and inline catalog Batch Edit Mode allowing moderators to select multiple SKUs, preview price/stock deltas, execute atomic audit-logged inventory transactions (INV-XXXX), track zero-result search demand gaps, and restock low-inventory items in one click.

8. Cloud Sync, Alerts, Maps & PWA Platform

Firebase Auth & Firestore multi-device sync for carts, wishlists, and orders; Price-Drop Alert subscriptions with drop simulation & email payload formatting; Google Maps Platform config integration; and installable PWA with Service Worker caching, app shortcuts, and maskable icons.

Security, Performance & Engineering Highlights Talking Points for Technical Interviews

Security & Data Integrity

  • Cryptographic Auth: Scrypt password hashing with per-user 16-byte random salts, timingSafeEqual comparisons, and automatic plaintext-to-scrypt migration.
  • Traffic Protection: Custom token-bucket IP Rate Limiter (120 general req/min, 30 sensitive auth/checkout req/min) returning standard Retry-After headers.
  • Server-Side Truth: Checkout line prices, tax (8.25%), promo codes, rig discounts, and RBAC checks are strictly enforced server-side.
  • Database Isolation: Owner-scoped Firestore rules + ESLint security rules validation preventing cross-user reads or role escalation.

UX Engineering & Testability

  • Pure Logic Decoupling: Core algorithms (pricing, SKU encoding, volatility stats, reticle clamping, security) isolated in src/logic/ with 83/83 unit tests passing.
  • Perceived Speed: Instant local SVG category tile placeholders upgrade seamlessly to high-res product photos without layout shift (CLS-safe 4:3 cards).
  • Bundling & Tooling: Automated esbuild IIFE bundles for React/D3 charts, QR scanner, and Firebase sync verified by tsc --noEmit.
  • Accessible Controls: Focus-trapped dialogs, roving tablists, 44px touch-target checks, and viewport classification helpers.
